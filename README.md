# Верстак — харнес для нейросетей на Android

Приложение-«пульт» для работы с нейросетью прямо на телефоне. Сама модель крутится в Termux (llama.cpp), а Верстак даёт вокруг неё всё, что делает из модели агента:

- **Чат с потоковым ответом** и сворачиваемым «ходом мыслей».
- **Агентный цикл**: модель сама вызывает инструменты, получает результат и продолжает (до N шагов).
- **Инструменты**: дата/время, калькулятор, «запомнить», чтение веб-страниц, команды bash в Termux, список/чтение/запись файлов в `~/verstak-workspace`.
- **Подтверждение опасных действий**: команды и запись файлов — только после кнопки «Разрешить».
- **Навыки** (пресеты): своя инструкция и свой набор инструментов. Встроены «Ассистент», «Агент Termux», «Разбор заказа».
- **Долговременная память** — факты, которые видны во всех чатах.
- **Счётчик контекста** и **автосжатие**: при 80% старая часть разговора сворачивается в сводку.
- **Несколько серверов**: llama.cpp или Ollama в Termux, домашний ПК в той же Wi-Fi, облако по ключу (любой OpenAI-совместимый API).
- Вложения текстовых файлов, история чатов, кнопка «Запустить модель» прямо из приложения.

## Как устроено

```
┌───────────── Телефон ─────────────┐
│  Верстак (APK)                     │
│   интерфейс + агентный цикл        │
│        │ HTTP 127.0.0.1            │
│        ├──► :8080 llama-server  ◄── модель .gguf (Termux)
│        └──► :8765 bridge.py     ◄── команды и файлы (Termux)
└────────────────────────────────────┘
```

## Как получить APK

Вариант А — **на домашнем ПК через Android Studio** (проще всего):
1. Установить Android Studio, открыть эту папку (`File → Open`).
2. Дождаться, пока он докачает всё нужное (внизу полоска).
3. `Build → Build App Bundle(s) / APK(s) → Build APK(s)`. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

Вариант Б — **бесплатно в облаке GitHub** (без установки чего-либо):
1. Создать репозиторий на github.com и загрузить туда содержимое этой папки (вместе с папкой `.github`).
2. Открыть вкладку **Actions** → «Собрать APK» — сборка запустится сама, 3–5 минут.
3. Внизу страницы сборки — архив **Verstak-apk**, внутри `app-debug.apk`.

APK скинуть на телефон и установить (разрешить установку из неизвестных источников).

## Первый запуск на телефоне

1. Меню → **Модель на телефоне**.
2. Поставить Termux из F-Droid (не из Google Play).
3. «Скопировать команду» → открыть Termux → вставить → Enter. Скрипт сам поставит llama.cpp, спросит модель (1.7B или 4B), скачает её и запустит.
4. Вернуться в Верстак — точка у названия модели станет зелёной.

После перезагрузки телефона — кнопка «▶ Запустить модель» (или в Termux: `bash ~/verstak/start.sh`).

## Файлы

- `app/src/main/assets/index.html` — весь интерфейс и логика агента.
- `app/src/main/java/.../MainActivity.java` — оболочка: WebView, сетевой мост, буфер обмена, запуск Termux.
- `app/src/main/assets/termux/setup.sh` (копия в `termux/`) — установка llama.cpp, модели, моста.
- `.github/workflows/build-apk.yml` — облачная сборка APK.
